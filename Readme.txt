--------Event Feedback Analyzer (AI + n8n)-----------------

A smart event feedback collection & analysis system using a modern UI, AI classification, and n8n automation.

# What This Project Does?

Collects feedback from users through a 3D interactive form

Sends data to n8n via webhook

Uses AI to analyze and categorize feedback

Automatically routes feedback based on category

Stores data in Airtable

Sends notifications (Email / Slack)

Responds instantly to the user

🧠 Core Functions

Feedback form (Name, Email, Rating, Message)

AI-based feedback classification

Complaint

Compliment

Feature Request

Automated routing using Switch node

Airtable record creation

Email & Slack alerts

Real-time webhook response

Loader & success UI handling

🛠 Tech Stack

Frontend: HTML, CSS, JavaScript

Automation: n8n Cloud

AI: Google Gemini (AI Agent)

Database: Airtable

Notifications: Gmail, Slack

Version Control: Git & GitHub

🔁 Workflow Flow
User → Web UI → n8n Webhook → AI Agent → Switch
→ Airtable → Notification → Response
